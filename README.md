## 🌐 Як це працює з GitHub (Покрокова інструкція)

Вам не потрібні платні сервери! GitHub надає безкоштовне пряме посилання (*Raw URL*) на будь-який файл:

```mermaid
flowchart LR
    A["💻 Ви за комп'ютером / телефоном"] -->|1. Додаєте пісню в songs.json| B["🐙 Ваш репозиторій на GitHub"]
    B -->|2. Додаток зчитує Raw URL| C["📱 Кнопка 🔄 у додатку"]
    C -->|3. Зберігає назавжди| D["💾 Пам'ять телефону (Працює ОФЛАЙН)"]
```

### Крок 1: Завантажте `songs.json` у свій репозиторій на GitHub
1. Створіть на GitHub репозиторій (наприклад, `songbook`) або використайте вже наявний.
2. Завантажте туди готовий файл **[songs.json](file:///C:/Users/Ruslan/.gemini/antigravity/scratch/songbook_android/songs.json)**.
3. Відкрийте цей файл на GitHub і натисніть кнопку **«Raw»**.
4. Скопіюйте посилання з адресного рядка браузера. Воно матиме такий вигляд:
   `https://raw.githubusercontent.com/<ваш_логін>/<назва_репозиторію>/main/songs.json`

### Крок 2: Вставте посилання в налаштування додатка
1. Відкрийте додаток на телефоні та натисніть значок **«⚙️» (Налаштування)**.
2. У розділі **«🌐 Синхронізація пісень із GitHub»** вставте своє посилання на `songs.json`.
3. Натисніть **«🔄 Оновити пісні з GitHub зараз»** (або кнопку `🔄` у шапці).

### Крок 3: Як додавати нові пісні в майбутньому?
Щоразу, коли ви захочете додати нову пісню:
1. Просто відкрийте `songs.json` на GitHub (навіть у браузері телефону) і додайте блок:
   ```json
   {
     "title": "Назва нової пісні",
     "author": "Виконавець",
     "defaultKey": "Am",
     "content": "[Am]Перший рядок тексту [Dm]з акордами...\n[E]Другий рядок..."
   }
   ```
2. Натисніть кнопку **Commit changes** на GitHub.
3. Відкрийте додаток на телефоні й натисніть кнопку **`🔄`**. Нова пісня миттєво з'явиться новим аркушем у пісеннику!
